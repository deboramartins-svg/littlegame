# 🕹️ RETRO_MINI_GAME

> *Mini-jogo interativo desenvolvido diretamente no navegador com HTML5 Canvas e JavaScript puro.*

---

## ⚡ Sobre o Projeto

O **RETRO_MINI_GAME** é uma experiência arcade leve e nostálgica, inspirada em clássicos dos fliperamas com um toque de estética cyberpunk/lo-fi. O jogo foi construído sem dependências externas, focando em otimização de performance, manipulação direta do `Canvas` em 2D e lógica de colisão fluida.

---

## 🚀 Tecnologias Utilizadas

* **HTML5 Canvas:** Renderização gráfica em tempo real e gerenciamento de quadros por segundo (`requestAnimationFrame`).
* **JavaScript (ES6+):** Lógica do jogo, movimentação, sistema de pontuação e detecção de colisões.
* **CSS3:** Estilização responsiva, fontes customizadas (`JetBrains Mono`) e efeitos visuais com tema escuro.
* **Web Audio API:** Sintetizador de áudio nativo para efeitos sonoros imersivos sem arquivos externos pesados.

---

## 🕹️ Como Jogar

1. Acesse o jogo hospedado via Vercel/GitHub Pages *(https://littlegame-tan.vercel.app)*.
2. Use as **setas do teclado** (ou toque na tela se estiver no mobile) para controlar o personagem/objeto.
3. Desvie dos obstáculos e acumule a maior pontuação possível antes que o tempo ou as vidas acabem!
